A responsive, single-page portfolio website for a Document Specialist with four years of experience in Word, PowerPoint and Excel formatting.

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Sections: Home, About, Skills, Work Samples, Experience, Contact
- Teal and gold colour theme with CSS variables, so colours are easy to change
- Mobile navigation menu that closes after a link is clicked
- Smooth scrolling and a "Back to top" button
- Automatic copyright year
- Reduced-motion support for accessibility

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5.3
- JavaScript (vanilla)
- Google Fonts (DM Sans, Manrope)

## Run Locally

```bash
git clone https://github.com/Arun-Python-code/mohamed-iqramullah-portfolio.git
cd mohamed-iqramullah-portfolio
```

Open `index.html` in your browser. No build step is needed.

## Customize

Change the colours in the `:root` block at the top of `style.css`:

```css
:root {
  --navy: #0c3137;
  --blue: #0e7c7b;
  --gold: #f2a93b;
}
```
